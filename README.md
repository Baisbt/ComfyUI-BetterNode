# ComfyUI-BetterNode

为 ComfyUI 默认节点提供一个统一的**「输入参数」**入口，让原本只能在节点面板上手动填写的内部参数
（如 KSampler 的 `seed` / `steps` / `cfg` / `sampler_name`）也能被外部驱动。

**全程不修改任何现有节点代码** —— 插件是纯前端扩展，通过运行时挂载实现，ComfyUI 核心与
任何原生/第三方节点文件都保持原样。

---

## 功能

- **右键菜单入口**：右键任意节点 →「输入参数」→ 列出该节点全部内部编辑参数
- **一键生成入参节点**：点击参数即生成一个入参节点，自动按该参数的规格建控件、
  拷贝当前取值、并连好线
- **下拉框选项同步**：`sampler_name` / `scheduler` 这类下拉参数的选项与目标节点完全一致
- **一个入参节点驱动多个节点**：同一参数的入参节点可同时连接多个同类节点，改一处全部生效
- **同义组复用**：`seed` 与 `noise_seed` 这类语义等价的参数共用同一个入参节点
- **批量外置**：一键为当前节点的全部内部参数建立入参节点，可整体撤销
- **中英双语**：跟随 ComfyUI 的语言设置自动切换

## 安装

把本仓库放到 ComfyUI 的 `custom_nodes/` 下即可，无需其他配置：

```
ComfyUI/custom_nodes/ComfyUI-BetterNode/
```

然后**重启 ComfyUI**（首次安装必须重启，`custom_nodes` 只在启动时扫描），
并**硬刷新浏览器**（Ctrl+Shift+R）。

自检：直接访问 <http://127.0.0.1:8188/extensions/ComfyUI-BetterNode/betterNode.js>
应能看到源码。若返回 404，说明后端未加载到插件。

## 使用

1. **右键节点** → 选择「输入参数」（位于菜单的「Extensions / 扩展」分组下）
2. 菜单会列出该节点全部内部编辑参数，形如：

   | 菜单条目 | 含义 |
   |---|---|
   | `步数` | 尚未外置 |
   | `种子 · 可复用` | 已有入参节点，但还未连到本节点 |
   | `种子 · 已外置 · ×3` | 已连到本节点，且该入参节点共连接 3 个目标 |
   | `噪声种子 · 已外置 · ×3 · 同义组共用` | 经同义组与 `seed` 共用同一个入参节点 |
   | `种子（不可用：该参数槽已被锁定）` | 置灰项，附原因 |
   | `全部外置（6 个待处理）` | 批量入口，仅在有待处理项时出现 |

3. **点击某个参数** → 生成/复用入参节点并自动连线
4. **点击「全部外置」** → 一次处理当前节点的全部内部参数（Ctrl+Z 可整体回退）

### 参数状态与随机化

入参节点自带 ComfyUI 原生的**值控制**控件（`fixed` / `increment` / `decrement` / `randomize`），
对 `seed` 这类参数可直接用来跑批换种子。该控件由 ComfyUI 原生提供，不属于本插件。

## 支持范围

| 对象 | 支持情况 |
|---|---|
| 标准 `INPUT_TYPES` 节点（含绝大多数第三方插件） | ✅ 自动适配 |
| 高级（advanced）/ 隐藏（hidden）参数 | ✅ |
| 子图节点（SubgraphNode） | ⛔ 置灰并说明 |
| 自定义 widget 类型（curve / imagecrop 等） | ⛔ 置灰并说明 |
| `socketless` 参数（无输入槽） | ⛔ 置灰并说明 |

不可用项一律**置灰并给出原因**，不会静默消失。

### 关于连线

**可连线参数（如 `model`、`positive`）不在本菜单中**。这些参数直接用 ComfyUI 原生的
拖线方式连接即可，插件不重复提供入口。

> 曾尝试过在菜单里提供连线功能，但拖拽方案经实测无法落点、替代方案体验不佳，
> 已整体下线。技术原因记录在 `TECHNICAL.md` §5.4。

## 目录结构

```
ComfyUI-BetterNode/
├── __init__.py              # 仅声明 WEB_DIRECTORY，不注册后端节点
├── web/
│   ├── betterNode.js        # 扩展入口，链式挂载 getExtraMenuOptions
│   ├── menu/buildMenu.js    # 菜单构建、文案、点击分发

│   │   ├── enumerate.js     # 参数枚举与分类
│   │   ├── guards.js        # 支持范围判定
│   │   └── synonyms.js      # 同义组（参数名 -> 复用键）
│   ├── actions/createInputNode.js  # 入参节点工厂、复用索引、批量外置
│   ├── i18n/                # 中英文字典与语言判定
│   ├── ui/notify.js         # 提示通道
│   └── compat/capability.js # 能力探测
├── tests/run.mjs            # 逻辑回归测试
├── DESIGN.md                # 产品设计文档

```

## 开发

```bash
node tests/run.mjs
```

无需启动 ComfyUI。测试脚本会在系统临时目录里还原出与浏览器一致的
`/extensions/<插件名>/` 目录结构，因此也能顺带验证相对导入路径是否正确。
当前 **36 项断言**。

修改前端代码后，刷新浏览器即可（前端脚本不缓存时）。改动 `__init__.py` 需重启 ComfyUI。

## 已知限制

- 依赖 ComfyUI 前端内部 API（`PrimitiveNode`、`getExtraMenuOptions` 等），
  版本升级后可能需要适配
- 菜单条目被归入「Extensions」分组，无法插入核心项之间（二级菜单机制限制）
- 子菜单不支持分隔线，分组与状态只能靠文案后缀表达
- `KSamplerAdvanced` 在 `add_noise = disable` 时会忽略 `noise_seed`，
  经同义组共用的种子在该节点上可能"改了没反应"
